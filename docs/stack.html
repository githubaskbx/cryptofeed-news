Stack

This repository is the public project page. The running product sits behind cryptofeed.news.

  • Web front end on Cloudflare.
  • An API and Postgres hold the feed, the hot list, and the daily brief.
  • AI writes translations, summaries, tags, and the first pass at grouping a story.

Readers do not need that split to use the site. If a page and its source disagree, the source wins.
